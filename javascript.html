Bagian A — Dasar bahasa

01

Pengenalan: apa itu JavaScript

Cara memasang, console, dan komentar.

JavaScript adalah bahasa pemrograman yang dijalankan oleh browser. Dengan JavaScript halaman bisa bereaksi: menghitung total belanja, menampilkan pesan saat tombol diklik, atau mengambil data dari internet. Ada dua cara menaruhnya di HTML:

<!-- 1. Internal: tag <script> di akhir <body>, setelah semua elemen HTML -->
<body>
    <h1>Halo</h1>
    <script>
        console.log("Halo dari JavaScript!");
    </script>
</body>

<!-- 2. Eksternal: file .js terpisah. "defer" = jalankan setelah HTML selesai dibaca -->
<head>
    <script src="script.js" defer></script>
</head>

console.log() adalah alat utama programmer untuk melihat isi sebuah nilai. Di halaman biasa hasilnya muncul di DevTools (tekan F12, atau ⌘ + Option + J di Mac, lalu buka tab Console). Di halaman ini hasilnya juga ditampilkan di kotak Console di sebelah kode.

JavaScript membedakan huruf besar dan kecil: console.log benar, Console.Log salah. Titik koma (;) di akhir baris boleh tidak ditulis, tapi sebaiknya dibiasakan.

02

Variabel: let dan const

Wadah bernama untuk menyimpan nilai.

  • const: nilainya tidak bisa diganti. Pakai ini sebagai pilihan pertama.
  • let: nilainya bisa diganti. Pakai kalau memang akan berubah, misalnya skor atau penghitung.
  • var: cara lama dengan aturan yang membingungkan. Kamu akan menemuinya di kode lama, tapi jangan dipakai.
03

Tipe data

Jenis-jenis nilai dan cara mengubah tipenya.

Tipe dasar: string (teks), number (angka, bulat maupun desimal), boolean (true/false), null (sengaja dikosongkan), dan undefined (belum diberi nilai). Untuk kumpulan data ada array dan object. Operator typeof memberi tahu tipe sebuah nilai.

Nilai dari kotak input HTML selalu berupa string, meskipun yang diketik angka. Ubah dulu dengan Number() sebelum dihitung.

04

Operator

Menghitung, membandingkan, dan menggabungkan syarat.

Selalu pakai === dan !==. Versi dua tanda (==, !=) diam-diam mengubah tipe data dan sering menghasilkan kejutan. Garis kuning di baris yang memakai == adalah peringatan dari linter, dan memang disengaja di contoh ini.

05

Mengolah string

Template literal dan method teks yang paling sering dipakai.

06

Kondisi: if, else, ternary, switch

Menjalankan kode yang berbeda sesuai keadaan.

Nilai yang dianggap false di dalam if (falsy): false, 0, "" (string kosong), null, undefined, dan NaN. Semua nilai lain dianggap true.

07

Perulangan: for, while, for...of

Menjalankan kode berkali-kali.

Hati-hati dengan perulangan yang syaratnya tidak pernah menjadi false, misalnya while (true) tanpa break. Browser akan macet; kalau terjadi, tutup tab lalu buka lagi.

08

Fungsi

Membungkus kode supaya bisa dipakai berulang kali.

Fungsi menerima masukan lewat parameter, lalu memberikan hasil lewat return. Fungsi baru berjalan ketika dipanggil dengan tanda kurung: sapa("Budi").

Bagian B — Kumpulan data

09

Array

Daftar nilai yang berurutan.

Array yang dibuat dengan const tetap bisa diubah isinya (push, pop, dan lainnya). Yang dilarang hanya mengganti seluruh array: buah = [...].

10

Object

Kumpulan pasangan kunci dan nilai yang menggambarkan satu benda.

11

Array berisi object dan JSON

Bentuk data yang paling sering ditemui di aplikasi sungguhan.

Daftar produk, daftar pengguna, daftar pesanan: hampir semuanya berbentuk array yang berisi object. Cara membacanya: ambil isi array dengan index dulu, lalu properti object dengan titik. JSON adalah format teks untuk menyimpan dan mengirim data seperti ini, misalnya antara browser dan server.

Perulangan for...of di atas bekerja, tapi untuk setiap pekerjaan (menjumlah, menyaring, mengubah) kamu harus menulis perulangan baru. Bagian berikutnya mengenalkan cara yang lebih singkat dan lebih jelas maksudnya: higher-order function.

Bagian C — Higher-order function

12

Fungsi sebagai nilai: callback dan higher-order function

Dasar dari map, filter, reduce, dan addEventListener.

Di JavaScript, fungsi adalah nilai, sama seperti angka atau string. Fungsi bisa disimpan di variabel, dikirim ke fungsi lain, dan dikembalikan dari fungsi lain.

  • Callback: fungsi yang dikirim ke fungsi lain, untuk dipanggil nanti oleh fungsi itu.
  • Higher-order function (HOF): fungsi yang menerima fungsi lain, atau mengembalikan fungsi.

Cara kerja map dan filter di balik layar

Method array seperti map dan filter hanyalah higher-order function yang berisi perulangan. Kalau ditulis sendiri, kira-kira seperti ini:

MethodHasilnyaDipakai untuk
forEachtidak ada (undefined)Melakukan sesuatu untuk setiap isi
maparray baru, panjang samaMengubah setiap isi
filterarray baru, bisa lebih pendekMenyaring isi yang memenuhi syarat

Callback untuk method array menerima tiga argumen: (isi, index, arrayAsli). Biasanya cukup isi dan index. Nama parameternya bebas: (p) =>, (produk) =>, dan (x) => sama saja.

13

forEach dan map

Melakukan sesuatu untuk setiap isi, dan mengubah setiap isi.

forEach hanya menjalankan callback untuk setiap isi. map menjalankan callback lalu mengumpulkan nilai yang di-return ke array baru. Aturan praktis: kalau kamu butuh hasilnya, pakai map.

Persiapan DOM: mengubah array menjadi HTML

Pola ini akan sangat sering dipakai: setiap isi array di-map menjadi potongan HTML, lalu digabung dengan join("") menjadi satu string. Di bagian DOM, string itu dipasang ke halaman.

14

filter, find, some, dan every

Menyaring, mencari, dan memeriksa isi array.

Callback untuk method-method ini mengembalikan true atau false: "apakah isi ini cocok?". Bedanya ada pada apa yang dikembalikan oleh method-nya.

Pakai filter kalau hasilnya boleh lebih dari satu, dan find kalau kamu yakin hanya butuh satu (misalnya mencari berdasarkan id). filter selalu mengembalikan array, meskipun isinya hanya satu atau kosong.

15

reduce

Merangkum seluruh isi array menjadi satu nilai.

reduce(callback, nilaiAwal) membawa sebuah nilai bernama akumulator dari satu putaran ke putaran berikutnya. Callback menerima (akumulator, isi) dan harus me-return akumulator yang baru. Nilai akhirnya bisa berupa angka, string, array, atau object.

Dua kesalahan paling sering: lupa menulis nilai awal (angka 0 atau {} setelah callback), dan lupa return di dalam callback yang memakai kurung kurawal. Kalau reduce terasa sulit, tidak apa-apa menulis for...of biasa dulu.

16

sort dan merangkai method (chaining)

Mengurutkan, lalu menggabungkan beberapa method menjadi satu alur.

Karena filter dan map mengembalikan array, hasilnya bisa langsung disambung dengan method berikutnya. Baca rangkaian seperti ini dari atas ke bawah, seperti resep.

Membuat dan mengulang tanpa array yang sudah ada

Kadang yang ingin diulang bukan array: sebuah object, atau sekadar "lakukan 5 kali". Ada cara untuk mengubahnya menjadi array supaya method di atas bisa dipakai.

Siap untuk DOM: hasil document.querySelectorAll() bisa langsung di-forEach, dan bisa diubah menjadi array biasa dengan Array.from() supaya map dan filter juga bisa dipakai.

Bagian D — Mengendalikan halaman (DOM)

17

DOM: memilih dan mengubah elemen

JavaScript melihat halaman HTML sebagai pohon object yang bisa diubah.

DOM (Document Object Model) adalah versi halaman HTML yang bisa diakses JavaScript lewat object document. Elemen dipilih dengan selector CSS yang sama seperti di pelajaran CSS. Mulai pelajaran ini ada dua kotak kode: HTML dan JavaScript. Keduanya bisa diedit.

18

Event: merespons klik, ketikan, dan gerakan

Menjalankan fungsi ketika pengguna melakukan sesuatu.

Pola dasarnya: elemen.addEventListener("namaEvent", fungsi). Fungsi itu menerima object event yang berisi keterangan tentang kejadiannya. Setelah menekan Jalankan, coba klik tombol, ketik di kotak input, dan arahkan kursor ke kotak paling bawah.

Event lain yang sering dipakai: submit (form dikirim), change (pilihan select/checkbox berubah), focus dan blur (kotak input aktif dan tidak aktif), serta DOMContentLoaded (HTML selesai dimuat).

19

Membuat dan menghapus elemen

Menampilkan isi array sebagai daftar di halaman.

Pola yang dipakai hampir semua aplikasi: data disimpan di array, lalu sebuah fungsi menggambar ulang tampilan dari data itu setiap kali datanya berubah. Elemen baru dibuat dengan document.createElement() lalu dipasang dengan append().

    20

    Form: membaca isian dan validasi

    Memeriksa isian pengguna sebelum diproses.

    Saat form dikirim, browser biasanya memuat ulang halaman. event.preventDefault() mencegah hal itu supaya JavaScript bisa memeriksa isian dulu. Isi kotak input dibaca dengan .value. Coba kirim form dalam keadaan kosong.

    { nama, email, umur } adalah singkatan dari { nama: nama, email: email, umur: umur }. Validasi di browser hanya untuk kenyamanan pengguna; di aplikasi sungguhan server tetap harus memeriksa ulang.

    Bagian E — Lanjutan

    21

    Asinkron: setTimeout, Promise, async/await, fetch

    Pekerjaan yang hasilnya baru ada nanti.

    Beberapa pekerjaan butuh waktu: menunggu beberapa detik, atau meminta data ke server. JavaScript tidak berhenti menunggu; kode berikutnya tetap jalan, dan hasilnya diproses ketika sudah siap. Perhatikan urutan angka di console contoh pertama.

    Mengambil data dari internet dengan fetch

    fetch() meminta data ke alamat lain dan mengembalikan Promise. Contoh ini mengambil daftar pengguna contoh dari jsonplaceholder.typicode.com, jadi butuh koneksi internet. Klik tombolnya setelah menekan Jalankan.

      22

      Menangani error dan menyimpan data

      try...catch, throw, dan localStorage.

      Error yang tidak ditangani menghentikan kode. Dengan try...catch, kode yang mungkin gagal dicoba dulu, dan kalau gagal, kamu yang menentukan apa yang terjadi. Pesan error juga sangat berguna: baca bagian sebelum titik dua (jenis error) dan sesudahnya (penyebabnya).

      Menyimpan data di browser dengan localStorage

      Semua variabel hilang ketika halaman dimuat ulang. localStorage menyimpan teks di browser secara permanen sampai dihapus. Simpan sebuah nama, lalu muat ulang halaman ini: namanya masih ada.
