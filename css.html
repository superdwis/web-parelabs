HTML menyusun isi halaman, CSS mengatur tampilannya. Di sini setiap konsep dikerjakan dua kali — dengan CSS biasa dan dengan Tailwind — supaya terlihat bahwa keduanya menghasilkan hal yang sama.

Cara membaca: kotak kiri berlabel CSS Vanilla, kotak kanan berlabel Tailwind. Bagian putih bergaris putus-putus adalah hasilnya, dan kotak gelap di bawahnya adalah kodenya. Bagian A — Dasar

01

Pengenalan: apa itu CSS dan cara memasangnya

Aturan CSS, tiga tempat menulisnya, dan cara memasang Tailwind.

CSS (Cascading Style Sheets) adalah bahasa untuk mengatur tampilan HTML: warna, ukuran, jarak, dan tata letak. Satu aturan CSS terdiri dari selector (elemen mana yang dipilih) dan satu atau lebih deklarasi berupa pasangan properti: nilai;.

/* selector   properti     nilai */
   h1       { color:       green;
              font-size:   32px; }

CSS vanilla bisa ditulis di tiga tempat:

<!-- 1. Inline: langsung di atribut style. Cepat, tapi sulit dirawat. -->
<h1 style="color: green;">Judul</h1>

<!-- 2. Internal: di dalam tag <style> pada <head>. Cocok untuk latihan satu file. -->
<head>
    <style>
        h1 { color: green; }
    </style>
</head>

<!-- 3. Eksternal: file .css terpisah. Ini yang dipakai di proyek sungguhan. -->
<head>
    <link rel="stylesheet" href="style.css">
</head>

Tailwind adalah kumpulan class siap pakai. Setiap class mewakili satu deklarasi CSS: text-green-700 berarti color: hijau, p-4 berarti padding: 1rem. Kamu tidak menulis file CSS, cukup menempel class di HTML. Untuk belajar, pasang dengan satu baris:

<head>
    <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
</head>
<body>
    <h1 class="text-3xl font-bold text-green-700">Judul</h1>
</body>

Dua hal yang perlu diingat. Pertama, tag script di atas hanya untuk belajar dan mencoba; di proyek sungguhan Tailwind dipasang lewat npm (Vite atau Tailwind CLI) supaya file CSS-nya kecil. Kedua, Tailwind membawa Preflight, yaitu reset yang menghapus gaya bawaan browser: margin heading dan paragraf jadi 0, bullet daftar hilang, tombol jadi polos. Karena halaman ini memuat Tailwind, contoh vanilla di sini juga menulis semua gayanya secara lengkap.

Selector elemen tanpa awalan, misalnya p { color: red; }, mengenai semua paragraf di halaman. Selector lain yang sering dipakai: h1, h2 (beberapa sekaligus), .a.b (punya dua class), .induk > .anak (anak langsung), dan * (semua elemen).

03

Cascade, specificity, dan pewarisan

Aturan mana yang menang ketika dua aturan mengenai elemen yang sama.

  • Specificity: selector yang lebih spesifik menang. Urutannya: inline style > id > class > elemen.
  • Urutan: kalau specificity sama, aturan yang ditulis paling akhir menang.
  • Pewarisan: properti teks seperti color dan font-size turun dari induk ke anak. Properti kotak seperti padding dan border tidak.

Teks ini mewarisi warna hijau dari induknya.

"merah" ditulis setelah "abu", jadi menang.

Id mengalahkan semua class.

Tailwind

Teks ini mewarisi warna hijau dari induknya.

Class pada elemen menimpa warisan.

Satu properti, satu class. Jangan pasang dua warna.

Tanda seru di akhir = !important.

Semua class Tailwind punya specificity yang sama, jadi masalah "aturan mana yang menang" hampir tidak muncul. Kalau dua class mengatur properti yang sama (text-red-700 text-blue-700), hasilnya bergantung pada urutan di file CSS Tailwind, bukan urutan di HTML. Karena itu pakai satu saja.

07

Box model: padding, border, margin

Setiap elemen adalah kotak yang berlapis.

Dari dalam ke luar: isi → padding (jarak isi ke garis tepi) → border (garis tepi) → margin (jarak ke elemen lain). Dengan box-sizing: border-box, nilai width sudah termasuk padding dan border, sehingga ukuran kotak lebih mudah dihitung.

Pola nama di Tailwind: p = padding, m = margin, lalu arah: t atas, r kanan, b bawah, l kiri, x kiri-kanan, y atas-bawah. Contoh: px-4, mb-2, mx-auto (menengahkan kotak). Tailwind sudah memakai border-box untuk semua elemen.

Bagian C — Tata letak

09

Display: block, inline, inline-block, none

Bagaimana sebuah elemen menempati ruang.

  • block: mengambil satu baris penuh, bisa diberi lebar dan tinggi. Bawaan div, p, h1.
  • inline: mengalir di dalam baris teks, lebar dan tinggi diabaikan. Bawaan span, a.
  • inline-block: sebaris seperti inline, tapi bisa diberi lebar dan tinggi.
  • none: elemen hilang dan tidak memakan tempat.

12

Position dan z-index

Mengeluarkan elemen dari alur biasa.

  • relative: tetap di tempatnya, tapi menjadi patokan bagi anak yang absolute.
  • absolute: ditempatkan terhadap induk terdekat yang punya position, lewat top, right, bottom, left.
  • sticky: ikut bergulir, lalu menempel ketika menyentuh batas yang ditentukan.
  • fixed: menempel pada layar dan tidak ikut bergulir.
  • z-index: menentukan elemen mana yang berada di depan ketika bertumpuk.

Transisi, transform, dan animasi

Membuat perubahan terjadi secara halus.

  • transform mengubah bentuk elemen: geser (translate), putar (rotate), perbesar (scale).
  • transition membuat perubahan nilai berjalan bertahap, bukan seketika.
  • animation menjalankan gerakan sendiri tanpa menunggu hover, berdasarkan @keyframes.

15

Desain responsif

Satu halaman yang menyesuaikan diri dengan lebar layar.

Prinsipnya mobile-first: tulis gaya untuk layar kecil dulu, lalu tambahkan perubahan untuk layar yang lebih lebar. Di CSS vanilla perubahan itu ditulis dalam @media (min-width: ...). Di Tailwind cukup dengan awalan: sm: (≥ 640px), md: (≥ 768px), lg: (≥ 1024px), xl: (≥ 1280px).

Coba: ubah lebar jendela browser. Kotak di bawah tersusun 1 kolom di layar sempit, 2 kolom mulai 640px, dan 4 kolom mulai 1024px.

16

Variabel CSS dan tema Tailwind

Menyimpan nilai di satu tempat supaya mudah diganti.

Variabel CSS ditulis dengan awalan dua tanda minus (--nama) dan dipakai dengan var(--nama). Ganti nilainya di satu tempat, semua yang memakainya ikut berubah. Di Tailwind, variabel yang ditulis di dalam @theme otomatis menjadi class baru.

CSS Vanilla

Teks ikut warna tema
Teks ikut warna tema

Tailwind

text-merek
border-merek

Di dalam <head>

<style type="text/tailwindcss">
    @import "tailwindcss";

    @theme {
        --color-merek: #246b53;
        --color-merek-muda: #d9f18b;
    }
</style>

Nama variabel di @theme menentukan class yang muncul: --color-merek menghasilkan bg-merek, text-merek, dan border-merek. Awalan lain: --font-* untuk jenis huruf dan --breakpoint-* untuk titik responsif. Mode gelap memakai awalan dark:, misalnya bg-white dark:bg-slate-900.

Kapan memakai yang mana?

  • CSS vanilla wajib dipahami lebih dulu. Tailwind hanya cara lain untuk menulis CSS; tanpa paham flex atau box model, class Tailwind tidak akan masuk akal.
  • Vanilla unggul ketika HTML harus tetap bersih, untuk gaya yang rumit (animasi khusus, selector kompleks), dan untuk halaman kecil tanpa alat tambahan.
  • Tailwind unggul dalam kecepatan: tidak perlu memikirkan nama class, tidak perlu berpindah file, dan ukuran serta warna konsisten karena diambil dari skala yang sama.
  • Keduanya bisa dipakai bersama. Banyak proyek memakai Tailwind untuk sebagian besar tampilan dan sedikit CSS vanilla untuk kasus khusus.

Latihan

  1. Buat file HTML latihan berisi beberapa h2, navigasi berupa daftar link, dan sebuah gambar. Tambahkan tag <style> di <head>, lalu ubah warna dan ukuran semua h2.
  2. Ubah <nav> di file itu menjadi menu mendatar dengan flexbox. Hilangkan bullet-nya dengan list-style: none.
  3. Beri gambar di file itu sudut bulat dan bayangan, lalu letakkan keterangannya tepat di tengah bawah gambar.
  4. Buat tiga kartu produk berjajar dengan grid. Di layar sempit kartu harus tersusun ke bawah.
  5. Buat tombol yang berubah warna dan sedikit terangkat saat di-hover, dengan transisi 0.3 detik.
  6. Ulangi latihan 2 sampai 5 di file baru yang memakai Tailwind, tanpa menulis satu baris CSS pun.
  7. Tantangan: buat ulang form order di pelajaran 17 dari nol tanpa melihat kodenya, dengan warna tema pilihanmu sendiri lewat variabel CSS.
